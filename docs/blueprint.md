# **App Name**: Diagram Weaver

## Core Features:

- JSON Input: Accept a JSON file as input to define the diagram structure, elements, and relationships.
- Diagram Rendering: Dynamically render an interactive diagram based on the JSON input. The diagrams code generator tool will intelligently lay out elements based on defined relationships and can accommodate node specifications as provided by diagrams.mingrammer.com.
- Zoom & Pan: Enable users to zoom in and out of the diagram and pan around to explore different sections.
- Hover Information: Display additional information about an element in an animated box when the user hovers over it.
- Node Library: Offer a wide range of built-in node types, following the collection of nodes offered at diagrams.mingrammer.com/docs/nodes/aws

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) for a professional and trustworthy feel.
- Background color: Light gray (#EEEEEE) for a clean and modern look.
- Accent color: Teal (#009688) to highlight interactive elements and information boxes.
- Body font: 'Inter' (sans-serif) for readability and a clean interface.
- Headline font: 'Space Grotesk' (sans-serif) for a bold, modern touch.
- Use simple, outlined icons to represent different diagram elements and actions.
- Employ a clean, well-spaced layout to ensure that diagrams are easy to understand and navigate.
- Use subtle animations for transitions and interactions, such as the hover information box, to create a smooth and engaging user experience.
