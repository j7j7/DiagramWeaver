How It Works

The viewer accepts diagram data via URL parameters:

Option 1: Inline JSON (Base64)

/viewer?json=eyJub2RlcyI6W10sImNvbm5lY3Rpb25zIjpbXSwiem9uZXMiOl19

Option 2: Remote JSON URL

/viewer?url=https://example.com/diagram.json
Note: Make sure your DiagramWeaver server is running on http://localhost:9002 (or update the base URL in the JavaScript below).
