1. Interactive Viewer (iframe)

Embed an interactive diagram viewer in an iframe. Users can pan, zoom, and see tooltips.

Usage: Use the /viewer route with either a json parameter (base64-encoded JSON) or a url parameter (URL to fetch JSON from).

Example 1: Using inline JSON (base64-encoded)

<iframe src="https://yourapp.com/viewer?json=eyJub2RlcyI6W10sImNvbm5lY3Rpb25zIjpbXSwiem9uZXMiOltdfQ==" width="100%" height="600" frameborder="0" ></iframe>

Example 2: Using remote JSON URL

<iframe src="https://yourapp.com/viewer?url=https://example.com/diagram.json" width="100%" height="600" frameborder="0" ></iframe>

Note: The iframe will automatically fit the diagram to view on load. Users can use the zoom controls in the top-right corner.

2. Static Image Export

Generate a static PNG or SVG image of the diagram for embedding in emails, PDFs, or documentation.

Usage: Export PNG/SVG/GIF from the editor (File → Export) or capture the viewer canvas client-side. There is no server export API in static deployments.

Editor export

Open the diagram in the editor and use File → Export for PNG, SVG, or GIF (quality and background options in the export dialog).

Viewer + screenshot

For embed-only workflows, load /viewer?json=… and use browser devtools or a headless browser screenshot if you need a raster from a shared link.

3. URL Parameter Encoding

How to encode your diagram JSON for the viewer URL:

JavaScript

const diagramData = { nodes: [...], connections: [...], zones: [...] }; // Encode to base64 const jsonString = JSON.stringify(diagramData); const base64Json = btoa(jsonString); const viewerUrl = `https://yourapp.com/viewer?json=${encodeURIComponent(base64Json)}`;

Python

import json import base64 from urllib.parse import quote diagram_data = { "nodes": [...], "connections": [...], "zones": [...] } # Encode to base64 json_string = json.dumps(diagram_data) base64_json = base64.b64encode(json_string.encode()).decode() viewer_url = f"https://yourapp.com/viewer?json={quote(base64_json)}"

4. Conference Page Integration Example

Example of how to embed a diagram on a conference page:

<!-- Conference Page HTML --> <div class="diagram-section"> <h3>Architecture Overview</h3> <p>Explore our system architecture:</p> <!-- Interactive Viewer --> <iframe src="https://yourapp.com/viewer?url=https://conference.example.com/diagrams/architecture.json" width="100%" height="600" frameborder="0" style="border-radius: 8px; box-shadow: 0 2px 8px rgba(0,0,0,0.1);" ></iframe> <!-- Pre-rendered PNG for email/PDF: export from editor and host the file --> <img src="https://conference.example.com/diagrams/architecture.png" alt="Architecture Diagram" style="max-width: 100%; height: auto;" /> </div>
